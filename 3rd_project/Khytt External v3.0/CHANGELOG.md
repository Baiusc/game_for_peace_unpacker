# CHANGELOG - Khytt CS2 External v3.0

- **GetPenetrationDepth**: New map parser logic to calculate wall thickness for Wallbang Indicators.
- **Wallbang ESP Tag**: Displays a discrete tag when an enemy is shootable through geometry.
- **Dynamic Color Buffering**: New settings for "Hidden" colors in the menu.
- **BspParser Integration**: Full 3D map geometry parsing for Mirgage, Inferno, etc.
- **Wall-Aware Visibility**: Triggerbot and ESP now respect physical map occlusions.
- **Grenade Bounce Physics**: Real-time trajectory prediction with surface reflection.
- **Zero-Delay Engine**: Total refactor of the W2S projection system.
- **ESP Changes**: New triple-layered box renders and rounded corners.
