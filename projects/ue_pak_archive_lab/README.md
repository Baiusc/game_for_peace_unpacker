# UE PAK 归档实验室

本子项目承接原有的和平精英 PAK 解包/打包代码，并将其定位为 **Unreal Engine PAK 归档格式学习工具**。它用于研究已获授权的本地归档：尾部信息、索引完整性、条目布局及压缩数据处理。

## 构建

```bash
cmake -S ../.. -B ../../build
cmake --build ../../build --target UE_PAK_UNPACK UE_PAK_REPACK
```

生成的可执行文件：

- `UE_PAK_UNPACK`：读取并导出归档条目。
- `UE_PAK_REPACK`：按已有实现重建归档。

## 目录

- `src/`：C 实现。
- `include/`：SHA-1 等共享头文件。
- `python/`：历史的格式实验脚本和 BMS 规则；运行前应在隔离目录中复制授权测试文件。

## 验证建议

1. 对输入与输出归档分别记录 SHA-256、文件大小和索引摘要。
2. 在独立副本上执行读写测试，保留原始归档不变。
3. 使用引擎或自建解析器验证索引偏移、大小和哈希一致性。

本子项目不以在线游戏客户端、账号或网络服务作为输入，也不包含用于改变在线游戏行为的工作流。
