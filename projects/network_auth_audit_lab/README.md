# 网络认证审计实验室

本子项目根据《某 FPS 外挂网络验证分析与网络验证服务端 API 的漏洞》的问题类型，改写为**防御性、离线认证审计练习**。重点不是复现客户端篡改或服务端伪造，而是识别客户端内嵌密钥、缺少重放保护、响应未验签与会话未绑定等设计缺陷。

## 运行

```bash
python3 analyze_fixture.py
```

默认读取 `samples/auth_trace.json`，该文件是人工构造的脱敏 JSON。脚本不含 socket、HTTP 客户端或任何外部服务地址；发现风险时以退出码 `1` 表示需要整改。

## 实践目标

1. 将认证流程建模为 `init -> login -> session` 的消息序列。
2. 审计每条消息的长期密钥暴露、nonce、时效、请求/响应完整性和会话绑定。
3. 输出可落地的整改项：服务端持有长期机密、短时令牌、双向完整性验证、nonce 去重及最小权限会话。

## 验证

```bash
python3 analyze_fixture.py; test $? -eq 1
```

预期输出为 5 项风险；这是合成样本刻意包含的问题，不代表任何真实服务的结论。

## 边界

只分析本地 JSON 或经授权导出的脱敏日志。不得把该脚本用于访问、重放、篡改或模拟第三方认证服务。
